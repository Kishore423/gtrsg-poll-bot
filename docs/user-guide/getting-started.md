# Getting started

This page walks you through your very first sign-in and what to do next.

## Prerequisites

- A Telegram account.
- Your Telegram handle (for example `@yourname`) must already have been added to
  the website by an administrator. If it hasn't, ask your admin to add you first
  — see [Account and access](account-and-access.md).
- The Telegram app on your phone or computer.

## Step 1 — Open the website

Go to the website address your administrator gave you and you will land on the
**Home** page with a sign-in panel.

## Step 2 — Start the login bot in Telegram

The website signs you in with a one-time code sent through a dedicated Telegram
login bot. Before you can receive a code, you must open that bot and press
**Start** once.

- On the sign-in panel, click **Open @…** (the login bot link). This shows a QR
  code you can scan with your phone's camera, plus an "Open on this device" link.
- In Telegram, press **Start** in the chat with the login bot.

You only need to do this once per device/account. It opens the conversation so
the bot is allowed to message you.

## Step 3 — Request your code

1. Enter your Telegram handle in the sign-in panel.
2. Click **Send code**.
3. The login bot sends you a six-digit code in Telegram.

## Step 4 — Enter the code

1. Type the six-digit code into the code field.
2. Click to verify.

Codes expire after a few minutes, so enter yours promptly. If it expires or does
not arrive, use **Resend code**.

## Step 5 — You're in

Once verified you'll see the Home page with your managed Telegram groups (if any)
and your name in the top-right navigation bar.

## What to do next

- If you manage polls, set up your [weekly template](common-workflows.md).
- Not sure a group is wired up correctly? Use **Verify bot** — see
  [Features](features.md).
- Explore [Features](features.md) for a tour of everything on each page.

If any step doesn't work, see [Troubleshooting](troubleshooting.md).
